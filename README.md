# Alura JavaScript 3

Repositório de estudos e projeto prático do curso **JavaScript: manipulando objetos**, da Alura.

## Propósito

Este repositório registra a construção de uma lista de compras interativa no navegador, usando JavaScript para representar os itens como objetos e controlar o comportamento da página.

O projeto permite adicionar, editar, marcar como comprado, remover e persistir itens no `localStorage`.

## Aprendizados

- criação e manipulação de objetos em JavaScript;
- uso de arrays de objetos para representar uma lista de itens;
- captura de elementos HTML com `getElementById` e `querySelectorAll`;
- criação de interações com `addEventListener`;
- leitura do elemento acionado com `event.target` e navegação pela estrutura HTML com `parentElement`;
- leitura de atributos personalizados com `getAttribute`;
- renderização dinâmica de elementos HTML com template literals;
- validação de itens duplicados com `some`;
- persistência de dados no navegador com `localStorage`;
- conversão de dados com `JSON.stringify` e `JSON.parse`;
- publicação do projeto com GitHub Pages.

## Organização dos exemplos

| Arquivo | Conceito principal |
| --- | --- |
| `index.html` | estrutura da lista de compras e identificação dos elementos da página |
| `main.js` | criação, renderização, edição, conclusão, remoção e persistência dos itens |
| `assets/style.css` | estilos da página, itens concluídos e lista de compras |

## Como executar

Abra o arquivo `index.html` em um navegador. A aplicação utiliza recursos externos do Bulma, Google Fonts e Font Awesome, portanto alguns estilos e ícones dependem de conexão com a internet.
